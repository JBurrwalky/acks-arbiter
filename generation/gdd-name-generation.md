## 1. Purpose

Define the name bank structure that a lightweight LLM populates during development (or at campaign creation time for procedurally generated cultures). Name banks are pre-generated JSON files — runtime name assignment is a table lookup, never an LLM call.

---

## 2. What Each Culture Needs

Every cultural group generated in `gdd-setting-generation.md` Layer 4 requires one complete name bank. A name bank contains the following elements:

### 2.1 Element Inventory

| Element | Count (minimum) | Description |
|---|---|---|
| Male first names | 200 | Personal names for male NPCs |
| Female first names | 200 | Personal names for female NPCs |
| Surnames / clan names | 150 | Family names, patronymics, or clan identifiers |
| Settlement names (hamlet) | 50 | Names suitable for hamlets and thorps |
| Settlement names (village/town) | 75 | Names suitable for villages and towns |
| Settlement names (city) | 40 | Names suitable for cities and metropolises |
| Realm / province names | 40 | Names for kingdoms, duchies, counties, baronies |
| River names | 30 | |
| Mountain / hill names | 30 | Peaks, ranges, ridges, passes |
| Forest / swamp names | 25 | Named wilderness regions |
| Dungeon / ruin names | 30 | Evocative names for adventure sites |
| Tavern / inn names | 40 | "The [Adjective] [Noun]" pattern or cultural variant |
| Ship names | 20 | For coastal/seafaring cultures (omit for landlocked) |
| Religious order names | 15 per religion | Temples, monasteries, holy orders |
| Military unit names | 20 | Legions, warbands, guard companies |
| Epithets / titles | 30 | "the Bold", "Ironfist", "Dawnbringer" — appended to notable NPCs |

### 2.2 Non-Human Name Banks

Demi-human races (dwarves, elves, halflings, etc.) each get a separate name bank with the same element inventory, sized at 60% of the human counts (fewer names needed since non-humans are less numerous). Beastman cultures (orcs, goblins, etc.) get a stripped-down bank: first names, clan names, lair/dungeon names, and military unit names only.

## 3. Format

Each name bank is a single JSON file per culture:

```json
{
  "culture_id": "keshite",
  "phonemic_notes": "Semitic-inspired. Hard consonants (k, sh, th, z). Short vowels. Stress on penultimate syllable. Names often 2-3 syllables.",
  "naming_conventions": {
    "surname_style": "patronymic",
    "patronymic_prefix": "al-",
    "female_suffix": null,
    "compound_settlement_names": true,
    "notes": "Surnames are patronymic: Karim al-Rashid = Karim son of Rashid. Women use bint- instead of al-. Settlement names often compound: Tal-Keshur, Zur-Ashanti."
  },
  "names": {
    "male_first": ["Karim", "Zuhair", "Tashfin", "..."],
    "female_first": ["Yasira", "Nalith", "Shemara", "..."],
    "surnames": ["al-Rashid", "al-Khoury", "al-Tarim", "..."],
    "settlements_hamlet": ["Zur-Fen", "Tal-Mura", "..."],
    "settlements_town": ["Kesh-Abar", "Tal-Keshur", "..."],
    "settlements_city": ["Zur-Ashanti", "Keshuria", "..."],
    "realms": ["Keshurat", "Tal-Shemara", "..."],
    "rivers": ["Zur-Nahl", "Tashwadi", "..."],
    "mountains": ["Kel-Thurga", "Ashmont", "..."],
    "forests": ["Shemwood", "Tal-Viridis", "..."],
    "dungeons": ["The Tomb of Zur-Karim", "Ashfell Depths", "..."],
    "taverns": ["The Gilded Hookah", "The Sand Viper", "..."],
    "ships": ["Dawn of Keshur", "Sandswift", "..."],
    "religious_orders": {
      "religion_ammonar": ["Order of the Burning Eye", "Temple of the Dawn Throne", "..."],
      "religion_istreus": ["Circle of the Silver Quill", "..."]
    },
    "military_units": ["The Keshite Spears", "Tal-Guard", "..."],
    "epithets": ["the Sandborn", "Ashblade", "Dune-Walker", "..."]
  }
}
```

### 3.1 Key Format Rules

- All arrays are flat string lists — no nested objects per name
- `phonemic_notes` is a human-readable string passed to the LLM when generating the bank, ensuring internal consistency. It is also available to the narration LLM for generating ad-hoc names if the bank runs dry.
- `naming_conventions` captures structural rules (patronymics, compound names, gendered suffixes) so the runtime name assembler can combine elements correctly
- `religious_orders` is keyed by religion ID since a culture may practice multiple religions
- Ship names are omitted entirely (key absent) for landlocked cultures

## 4. LLM Generation Prompt

The name banks are generated by a lightweight LLM (not at runtime — during development or at campaign creation). The prompt structure:

```
Generate a complete name bank for a fantasy culture with these characteristics:

Culture ID: {culture_id}
Description: {cultural_flavor_text from gdd-setting-generation.md Layer 7}
Terrain affinity: {terrain_affinity}
Alignment tendency: {alignment}
Real-world phonemic inspiration: {inspiration_hint}
  (e.g., "Semitic-inspired", "Norse-inspired", "West African-inspired",
   "Slavic-inspired", "East Asian-inspired", "Celtic-inspired",
   "Greco-Roman-inspired", "Persian-inspired")

Requirements:
- All names must share a recognizable phonemic palette so they sound 
  like they come from the same language
- Names must be pronounceable by English speakers
- Names must NOT be real-world place names or historical figure names
- Settlement names should feel appropriate to their size 
  (hamlets = short/simple, cities = grander/longer)
- Dungeon names should feel ominous or ancient
- Tavern names should feel inviting or colorful
- Provide exactly the counts specified in the element inventory

Output as JSON matching the schema provided.
```

### 4.1 Phonemic Palette Assignment

Each cultural group gets a real-world phonemic inspiration assigned during setting generation (Layer 4). This is the seed that gives the LLM direction. The generator ensures no two adjacent cultures share the same inspiration, so neighboring peoples sound distinct.

Available palette inspirations (expandable):
- Semitic (Arabic/Hebrew)
- Norse / Germanic
- Celtic / Gaelic
- Slavic
- Greco-Roman
- Persian / Central Asian
- West African
- East Asian (Chinese/Japanese/Korean-inspired)
- South Asian (Sanskrit-inspired)
- Mesoamerican
- Polynesian
- Turkic / Steppe

## 5. Runtime Name Assignment

At runtime, name assignment is pure table lookup:

```
1. Determine the hex's dominant culture (from demographic weights)
2. Load that culture's name bank
3. Draw a name from the appropriate array (male_first, settlements_town, etc.)
4. Mark the name as used (prevent duplicates within a campaign)
5. Apply naming conventions:
   - If patronymic: assemble "FirstName + prefix + Father'sName"
   - If compound settlement: name is already compound in the bank
   - If epithet needed: append a random epithet for notable NPCs
```

If a name bank is exhausted (all names used), fall back to the LLM with the `phonemic_notes` as guidance to generate a small batch of additional names on demand. This should be rare given bank sizes.

## 6. Non-Human Banks

| Race | Phonemic Direction | Naming Convention |
|---|---|---|
| Dwarf | Heavy consonants, short words, hard stops (k, g, d, th) | Clan name first, personal name second |
| Elf | Flowing vowels, soft consonants (l, r, n, th, s), long names | Single compound name, no surname; house name for nobility |
| Halfling | English-adjacent, pastoral, cheerful sounds | First name + family name (hobbit-adjacent convention) |
| Orc | Guttural, aggressive (g, k, z, ugh, ar, gash) | Personal name + tribal name (e.g., "Grukk of the Bloodmaw") |
| Goblin | Short, sharp, clipped (ik, ak, snit, grib) | Personal name only; chieftains get epithets |
| Gnoll | Growling, hyena-like (gnash, yip, rrh, kk) | Pack name + personal name |

These are generated once and shared across all campaigns (non-human naming doesn't vary by setting the way human cultural naming does). They can be bundled as static data files.
