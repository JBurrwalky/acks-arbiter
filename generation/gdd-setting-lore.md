# 1. Document Purpose

## 1.1 Scope

This document will outline the shared setting lore that will pre-populate all setting generation sessions at runtime and will inform setting generation decisions. It will contain basic information on setting history, metaphysics, available cultures for populating a setting, and alignment definitions for Lawful, Neutral, Chaotic, and various pantheons of gods and religious doctrines.

It will NOT be an exhaustive description of any specific cultures, it will not dicate a specific map or climate type, it will not dictate setting history beyond the deep history of the setting, it will not dictate the existence of any specific in-game NPCs.
